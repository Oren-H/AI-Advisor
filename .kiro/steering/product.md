# AI Course Advisor Product Overview

The AI Course Advisor is an intelligent course recommendation system for Columbia University students. It combines conversational AI, vector search, and natural language processing to help students find and select courses based on their preferences, schedules, and academic goals.

## Core Features

- **Natural Language Queries**: Students can ask for courses in plain English
- **Conversational Interface**: Interactive dialogue with memory of user preferences and conversation history
- **Intelligent Course Search**: Vector-based semantic search across course descriptions and metadata
- **Smart Filtering**: Automatic generation of filters from natural language (department, time, credits, etc.)
- **Schedule Conflict Detection**: Helps avoid time conflicts between courses
- **User Profile Building**: Learns and remembers student preferences over time
- **Intent Classification**: Automatically categorizes queries as specific course searches, general advisory, or mixed

## Target Users

- Columbia University students seeking course recommendations
- Academic advisors looking for AI-assisted guidance tools
- Students planning their semester schedules

## Key Value Propositions

1. **Personalized Recommendations**: Tailored course suggestions based on student profiles and preferences
2. **Natural Interaction**: No need to learn complex search interfaces - just ask in plain English
3. **Comprehensive Search**: Searches across course descriptions, metadata, and scheduling information
4. **Context Awareness**: Maintains conversation context for follow-up questions and refinements
